TOTP / 2FA Code Generator

Paste a Base32 secret, get the current code. Same result as Google Authenticator or Authy. Everything runs in your browser — the secret is never sent anywhere.

Enter a secret to start.
How to use
  • The secret is the string shown under "Can't scan the QR code?" when you enable 2FA, or the 2FA key that came with an account.
  • Codes change every 30 seconds. If a code is rejected, check that your device clock is correct.
  • For long-term use, import the secret into an authenticator app instead of keeping it in a browser tab.
